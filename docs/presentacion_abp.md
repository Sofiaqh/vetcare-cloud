# Presentación Ejecutiva y Técnica: VetCare Cloud

## Diapositiva 1: Portada
- **Título:** VetCare Cloud — Solución Móvil y Cloud para Gestión Veterinaria
- **Subtítulo:** Taller ABP - Entrega 1 | Diseño de Aplicaciones Móviles
- **Año:** 2026

## Diapositiva 2: Planteamiento del Problema
- Descentralización de historiales médicos de mascotas.
- Olvido frecuente de vacunas y controles periódicos por parte de los dueños.
- Necesidad de un canal digital directo entre clientes y servicios médicos veterinarios.

## Diapositiva 3: Arquitectura Cloud y Solución Técnica
- **Diagrama:** App Móvil ➔ API REST Java Spring Boot ➔ PostgreSQL Cloud (SQL).
- **Justificación:** Uso de Java por estabilidad y escalabilidad, combinado con un motor SQL relacional para garantizar integridad referencial en citas y pacientes.

## Diapositiva 4: Modelo de Datos y Funcionalidades
- **Entidades SQL:** Usuarios, Mascotas, Citas y Historial de Vacunas.
- **Funcionalidades Clave:** Registro de mascotas, agendamiento de citas, consulta de historial clínico.

## Diapositiva 5: Conclusiones y Plan de Entrega Final
- **Logros Entrega 1:** Definición de arquitectura Cloud, diseño del modelo de datos en SQL y estructura base del repositorio en GitHub.
- **Siguientes pasos:** Integración final de interfaces móviles y despliegue continuo de endpoints REST.
